## ✨ About

A personal birthday gift turned into a website: smooth animations, interactive moments, and a warm, heartfelt design. No frameworks, no build step, just clean front-end code.

## 🎯 Features

- 🎨 Modern, responsive design that works on phones, tablets, and desktops
- 🎆 Smooth animations and interactive effects
- 🌍 Right-to-left (RTL) Arabic text support
- ⚡ Lightweight and fast: no dependencies, no build tools

## 🛠️ Built With

| Technology | Purpose |
| ---------- | ------- |
| HTML5 | Structure and content |
| CSS3 | Styling, layout, and animations |
| JavaScript | Interactivity and effects |

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/shena9y/BirthDay.git

# Enter the folder
cd BirthDay

# Open index.html in your browser
```

No installation needed. Just open `index.html`.
